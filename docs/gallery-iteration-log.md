# Seeker Gallery 迭代日志 — 「小摄影师的作品集」

> 任务：40 分钟一轮，在同一版本上持续精修至国际摄影展览品质。原则：只打磨一个版本；摄影作品为中心；动效克制；移动端独立完整体验。权重：摄影呈现 25%
> / 整体审美 20% / 交互 20% / 排版节奏 15% / 动效 10% / 移动端 10%。

## 基线（2026-11-05 00:45，9 个既有提交 bbeb722…09c4421）

**现状**：画廊页 /welfare/gallery/（5 主题章 × 序列观看器 + 灯箱），落地页入口区块。已具备：LQIP 占位、邻图预热、scrollspy、触屏滑翻、无 JS 降级、暗色模式、进出过渡。

**基线自评**（对照六维）：

- 摄影呈现 7/10：照片不裁切、大图占比足；但观看器卡片的主色渐变垫底在照片加载完成后仍可见，喧宾夺主，更像占位而非画框
- 整体审美 7/10：编辑部刊头成熟；章头幽灵期号+宋体成立；章节之间呼吸均匀
- 交互 8/10：键盘/触屏/滑动/预热齐备；灯箱功能完整

- 动效 7/10：淡入克制；灯箱过渡得体
- 移动端 8/10：全屏灯箱、滑翻、60vw 大图

**本轮候选问题**（审查得来）：

1. 【呈现】观看器垫底渐变在图片就位后仍满幅可见——应让「画框」安静下来，垫色只在加载期存在

3. 【呈现】开篇图（章节封面）与后续图的展示规格无差异，序列的「首图定调」在展示层没有体现
